**Contents:**

1. Exploratory analysis: initial_sens_jup.ipynb

2. DEL prediction model training Modelling_regression.ipynb

3. Universal model training and testing: Universal.ipynb

4. Candidate site creation: making_candidate_site.ipynb

5. Clustering implementation: candidate_site_clustering.ipynb
